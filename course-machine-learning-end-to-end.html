Module 1 · Framing a Problem as Machine Learning

34 min

Not every problem needs a model — learn to tell the difference.

  • When a simple rule beats a model
  • Choosing a metric before you choose an algorithm
  • Setting up a reproducible training environment

Module 2 · Data Preparation That Doesn't Leak

48 min

Most broken models were broken before training even started.

  • Train/test splits that don't quietly cheat
  • Handling missing and imbalanced data honestly
  • Project: prepare a real dataset end to end

Module 3 · Training a Baseline You Can Trust

50 min

Always beat a boring baseline before celebrating a fancy model.

  • Picking a baseline that's actually hard to beat
  • Cross-validation without fooling yourself
  • Reading a confusion matrix like it matters

Module 4 · Choosing and Tuning a Real Model

55 min

Move past the default settings.

  • Model selection based on your actual constraints
  • Hyperparameter tuning without brute-forcing forever
  • Avoiding overfitting to your validation set

Module 5 · Evaluating Honestly

45 min

A model that looks great in a demo can still fail in production.

  • Metrics that match the real-world cost of errors
  • Testing on data that resembles production, not training
  • Project: write an honest evaluation report

Module 6 · Serving a Model Behind an API

52 min

A model nobody can call isn't shipped.

  • Wrapping a model in a simple, real API
  • Latency and cost tradeoffs at inference time
  • Versioning a model without breaking callers

Module 7 · Monitoring for Drift and Failure

42 min

Models degrade quietly — catch it before your users do.

  • Detecting data drift after deployment
  • Logging predictions without creating a privacy mess
  • Deciding when it's time to retrain

Module 8 · Final Review and Handoff

36 min

Ship it like someone else will maintain it — because they might.

  • Documenting a model so it survives you leaving
  • Presenting results and limitations honestly
  • Final review session with your mentor
What you'll walk away with

A trained model, served behind a real API
